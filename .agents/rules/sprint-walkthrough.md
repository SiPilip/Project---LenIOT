# Sprint Walkthrough Delivery Rule

Setiap kali menyelesaikan sebuah Sprint (seperti Sprint 2.4, 2.5, 2.6, dst.) atau implementasi fitur besar, AI Coding Agent **WAJIB** mendokumentasikan hasil pekerjaan dan menyimpannya secara permanen ke direktori:

`D:\UNSRI_DATA\WEB PROGRAMMING\Project - Skula\documents\walkthrough\sprint{X.Y}.md`

## Standar Format Dokumentasi:
1. **Ringkasan Fitur & Arsitektur Sprint**: Penjelasan modul, rute, dan tujuan operasional sekolah.
2. **Rincian Implementasi per Pilar / Tab**: Breakdown komponen visual, state management, dan alur UX.
3. **Data Contracts & Schemas**: Detail tipe data TypeScript, skema validasi Zod, dan integrasi API Client.
4. **Penyempurnaan Taktis & Edge Cases**: Dokumentasi mitigasi anomali lapangan (seperti dual-gatekeeper, background workers, prorata manual).
5. **Validasi Mutu & Bukti Uji**: Status `lint` (TypeScript), `build`, rekaman demo video/gambar, dan hash Conventional Commit Git.
